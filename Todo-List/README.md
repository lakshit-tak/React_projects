# React To-Do List

A To-Do List application built using React.js.

## Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Save in local storage
- Edit task
- Filter task like all, complete, pending

## Technologies

- React.js
- JavaScript
- JSX
- CSS
- Vite
