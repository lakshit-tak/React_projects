# React Notes-App

A responsive Notes App built with React.js for creating, searching, editing, and deleting notes.

## Features

- Add notes with title and content
- Search notes by title
- Edit and delete notes
- Delete confirmation
- Local Storage persistence
- Responsive UI

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Local Storage
